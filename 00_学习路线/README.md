# 学习路线

## 第 1 阶段：基础打底（2-4 周）

目标：能看懂基础模型代码，能独立训练一个图像分类模型。

- Python / NumPy / Matplotlib
- PyTorch：Dataset、DataLoader、Module、训练循环
- 图像处理：卷积、滤波、颜色空间、增强
- CNN 基础：LeNet、AlexNet、VGG、ResNet

## 第 2 阶段：核心任务（4-8 周）

目标：理解主流 CV 任务的基本范式，并跑通公开代码。

- 图像分类：ResNet、EfficientNet、ViT
- 目标检测：Faster R-CNN、YOLO、DETR
- 图像分割：FCN、U-Net、DeepLab、Mask R-CNN、SAM
- 度量与评估：Accuracy、mAP、IoU、Dice、F1

## 第 3 阶段：现代视觉模型（4-8 周）

目标：读懂近几年主流论文，并能做改动实验。

- Vision Transformer / Swin Transformer
- Self-supervised learning：SimCLR、MoCo、MAE、DINO
- Diffusion Models
- CLIP、BLIP、视觉语言模型
- Segment Anything / foundation models

## 第 4 阶段：项目实战（持续）

目标：完成一个能展示的完整项目。

- 选择一个明确场景
- 找数据或自己标注小数据集
- 建 baseline
- 做误差分析
- 优化模型和数据
- 写成报告或 Demo
