# 计算机视觉学习项目

这个项目用于系统学习计算机视觉：读论文、跑代码、整理数据集、记录实验和做小项目。

## 推荐学习主线

1. **基础能力**：Python、PyTorch、线性代数、概率统计、图像处理基础。
2. **经典视觉任务**：图像分类、目标检测、图像分割、关键点/姿态估计。
3. **现代模型结构**：CNN、Transformer、ViT、DETR、SAM、Diffusion、视觉语言模型。
4. **论文复现**：从轻量模型开始，逐步复现实验、指标和消融。
5. **实战项目**：选一个可落地主题，完成数据、训练、评估、推理和展示闭环。

## 目录说明

- `00_学习路线/`：阶段规划、周计划、学习检查清单。
- `01_论文阅读/`：论文清单、阅读笔记、按方向分类。
- `02_代码复现/`：复现代码、baseline、训练脚本和模板。
- `03_数据集/`：数据集下载、处理、标注和版本记录。
- `04_笔记/`：基础知识、模型结构、训练技巧。
- `05_实验记录/`：实验日志、结果、参数和运行记录。
- `06_工具与环境/`：环境配置、依赖、常用命令。
- `07_项目实战/`：阶段性小项目和最终作品。
- `assets/`：图片、图表、论文截图等素材。
- `outputs/`：模型输出、可视化结果、报告草稿。

## 建议使用方式

每读一篇论文，至少留下三样东西：

- 一页摘要：问题、方法、贡献、局限。
- 一个复现入口：官方代码或你自己的最小复现。
- 一个实验记录：数据、参数、指标、现象、下一步。
