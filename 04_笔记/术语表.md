# 计算机视觉术语表

| 术语 | 含义 | 备注 |
|---|---|---|
| CNN | 卷积神经网络 | 视觉任务基础结构 |
| Backbone | 主干网络 | 提取特征，如 ResNet、Swin |
| Neck | 特征融合模块 | 检测模型常见，如 FPN |
| Head | 任务输出头 | 分类、检测、分割输出 |
| mAP | mean Average Precision | 检测常用指标 |
| IoU | Intersection over Union | 检测/分割常用指标 |
| Dice | Dice coefficient | 医学分割常用指标 |
| Augmentation | 数据增强 | 提升泛化能力 |
| Transfer Learning | 迁移学习 | 使用预训练模型微调 |
