# 论文阅读

## 阅读模板

每篇论文建议按这个结构记录：

1. **论文信息**：标题、年份、会议/期刊、代码链接。
2. **解决什么问题**：任务、输入输出、痛点。
3. **核心方法**：模型结构、训练方式、损失函数、关键创新。
4. **实验结论**：数据集、指标、对比方法、主要结果。
5. **我学到什么**：可复用技巧、适合复现的部分。
6. **疑问与局限**：没看懂的地方、可能的问题。

## 读论文顺序建议

- 先读综述和经典论文，建立地图。
- 再按任务读：分类 → 检测 → 分割 → Transformer → 多模态/生成。
- 最后读你项目方向相关的最新论文。
